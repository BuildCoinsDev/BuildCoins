# BuildCoins

**Do work. Earn coins. Build the future.**

BuildCoins is an open-source, community-driven platform where anyone in the world can contribute their skills and get compensated in cryptocurrency tokens. Developers, designers, lawyers, marketers, writers, security experts. Everyone has something to offer to this project.

## How It Works

1. **Browse tasks** on [buildcoins.dev](https://buildcoins.dev) — tasks span development, design, legal, marketing, documentation, security, and more
2. **Submit your work**
3. **Get paid in BuildCoins** when your contribution is accepted

No interview. No application. No gatekeeping. If your work is good, you get paid.

Even if there's no open task for it, valuable contributions are always rewarded.

## Why BuildCoins?

The software industry builds what sells the most, not what is best for the user. We're here to change that.

BuildCoins is not a company. It's not a startup looking for an exit. It's a bet on open collaboration, thousands of people around the world contributing what they're best at. This structure can outperform the traditional model. We build software that lasts, not software that sells.

## What Can I Contribute?

Whatever you're good at:

- **Developer?** Write code, fix bugs, build features
- **Designer?** Create logos, UI/UX, branding
- **Lawyer?** Help navigate compliance and payments legality
- **Marketer?** Grow the community, manage socials
- **Writer?** Draft documentation, whitepapers, content
- **Security expert?** Audit code, harden infrastructure
- **Business strategist?** Shape the roadmap
